CURRENT IMPLEMENTATION

AES-256-GCM

The vault encrypts file contents with authenticated AES-GCM and a fresh random nonce for every file.

  • Strong confidentiality and tamper detection
  • Efficient for files of any normal size
  • Implemented by this demo
POST-QUANTUM KEY LAYER

ML-KEM (Kyber)

ML-KEM is designed to establish shared secrets against attackers equipped with future quantum computers.

  • Used for key establishment, not bulk file data
  • More key material and computation than AES alone
  • Ready to pair with symmetric encryption
Recommended direction: keep AES-256-GCM for file data and add ML-KEM around key exchange when deploying a production post-quantum design.
