ABOUT THE PROJECT

Security You Can Inspect

Quantum-Safe File Vault is a small, transparent demonstration of secure file handling and post-quantum migration thinking.

What this vault does

Files are encrypted locally with AES-256-GCM. The encrypted file and its separate key file can then be downloaded and stored independently.

Why quantum-safe matters

Large quantum computers could weaken some public-key systems. ML-KEM is a standardized post-quantum key-establishment algorithm intended to help protect future exchanges.

What this demo does not claim

The selectable mode labels are educational. The current implementation uses AES-256-GCM; ML-KEM and hybrid key exchange are documented comparison paths, not yet wired into encryption.

Project principles

ConfidentialityReadable files become protected ciphertext.
IntegrityAES-GCM detects altered encrypted data.
ClarityThe key boundary and algorithm status stay visible.
